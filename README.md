# Sudoku Gang

ซูโดกุแข่งกับเพื่อนแบบเรียลไทม์ เล่นบนเบราว์เซอร์มือถือ ไม่มีโฆษณา

## ฟีเจอร์
- เล่นพร้อมกันได้สูงสุด 10 คน เข้าห้องด้วยรหัส 4 ตัวอักษรหรือลิงก์ (มีปุ่มแชร์)
- 4 ระดับ: ง่าย / กลาง / ยาก / โหด (ทุกโจทย์มีคำตอบเดียว)
- โหมด **คลาสสิก**: แย่งเติมทีละช่อง คนที่ 1/2/3 ได้ +10/+6/+3 คนที่เหลือได้ +1 ถ้าเติมผิดได้ −5 และช่องนั้นถูกล็อก ช่องที่ใครเติมถูกก่อนจะเป็นสีของคนนั้น
- โหมด **ฮาร์ดคอร์**: ไม่มีแต้ม ไม่บอกว่าผิด เห็นแค่ % ความคืบหน้าของเพื่อน ใครแก้ถูกทั้งกระดานก่อนชนะ
- ห้องสาธารณะ / ส่วนตัว และหน้ารวมห้องที่เปิดอยู่
- แชตในห้อง พร้อมข้อความด่วน
- จบเกมแล้วมีห้องถัดไปให้เข้าต่อได้ทันที
- โน้ตดินสอ, ไฮไลต์เลขเดียวกัน, ลบโน้ตอัตโนมัติ, เปิด/ปิดสีผู้เล่น, โหมดมืด, สั่นเมื่อเติมผิด
- หลุดหรือรีเฟรชแล้วกลับเข้าห้องเดิมได้ คะแนนและกระดานยังอยู่
- เพิ่มลงหน้าจอโฮมของมือถือได้ (PWA)

## รันบนเครื่อง
ต้องมี Node.js 18 ขึ้นไป

```bash
npm install
npm start
```

เปิด http://localhost:3000

เล่นกับเพื่อนที่ใช้ Wi-Fi เดียวกัน: เปิด `http://<IP ของคอมพิวเตอร์>:3000` บนมือถือ
(ดู IP ได้ด้วยคำสั่ง `ipconfig` บน Windows)

## นำขึ้นเว็บให้เพื่อนเล่นจากที่ไหนก็ได้
เป็นแอป Node.js ตัวเดียว (ไฟล์หน้าเว็บ + WebSocket) จึงใช้โฮสต์ที่รองรับ Node และ WebSocket ได้ เช่น Render, Railway หรือ Fly.io
- Build command: `npm install`
- Start command: `npm start`
- พอร์ตอ่านจากตัวแปร `PORT` อัตโนมัติ
- Health check: `/healthz`

ห้องเก็บอยู่ในหน่วยความจำของเซิร์ฟเวอร์ ถ้ารีสตาร์ตเซิร์ฟเวอร์ ห้องที่เปิดอยู่จะหายไป
